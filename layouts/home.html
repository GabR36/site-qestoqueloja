QEstoqueLoja

O QEstoqueLoja é um software ERP gratuito e de código aberto, emissor de Nota Fiscal Eletrônica e focado na facilidade de uso.

Baixar para Windows Baixar para Linux

Funcionalidades

  • Totalmente gratuito
  • Emissão de Nota Fiscal Eletrônica (NF-e) e Nota Fiscal do Consumidor Eletrônica (NFC-e) para o regime simples nacional
  • Controle de estoque e preço de produtos
  • Uso de código de barras
  • Importação de produtos a partir da NF-e
  • Instaladores para Windows e Linux
  • Envio de dados para o contador via e-mail
  • Envio de notas fiscais para o cliente via e-mail
  • Ponto de Venda (PDV)
  • Importação de dados de clientes a partir do CNPJ
  • Criação de orçamentos
  • Separação de produtos com nota fiscal e sem
  • Vendas a prazo
  • Relatórios de vendas, lucro, formas de pagamento, valor de notas fiscais
  • Emissão de notas fiscais em contingência
  • Impressão de etiquetas e recibos
